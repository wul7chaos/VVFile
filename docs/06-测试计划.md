## 3. 功能清单

### 3.1 浏览

- [ ] 冷启动进入首页，双窗格均显示 `/sdcard`
- [ ] 左右窗格独立前进/后退/上级，历史不串
- [ ] 底部「同步」：未选中窗格跳到选中窗格的目录，且活动窗格不跟着变
- [ ] 顶部「⋮」：回到根目录跳到 `/storage/emulated/0`；显示/隐藏隐藏文件；同步窗格
- [ ] 顶部「⋮」不再有「刷新」项
- [ ] 在 `/` 处按返回 / 侧滑：应用留在原地，不退出
- [ ] 在右窗格滑动/拖拽/点击即成为活动窗格（不用先点顶部标签）
- [ ] 点 `.zip` 直接进压缩包浏览，不再弹「选择打开方式」
- [ ] 压缩包内：目录逐层进出、返回键先退一层再关闭、点文件解到缓存并打开
- [ ] 压缩包内条目显示大小/时间；条目数正确
- [ ] 损坏的 zip 显示错误态不崩溃
- [ ] 其他应用「打开方式 → 定位所在目录」：一个窗格跳到该文件目录并选中文件、滚到可视区
- [ ] 定位到目录时直接进入该目录；定位到已删除文件时退化为只打开父目录
- [ ] 点面包屑打开跳转面板：预填当前路径、`确定` 生效、`粘贴` 取剪贴板
- [ ] 跳转输入前缀出候选（`/sdc` → `/sdcard/`），点候选补全并列出该目录内容
- [ ] 跳转到不存在的路径给出错误态，不崩溃
- [ ] 路径栏长按复制完整路径
- [ ] 面包屑点击任意层级跳转正确
- [ ] 空目录、无权限目录、超长文件名、中文/emoji/空格文件名
- [ ] 5000+ 项目录滚动不卡顿、不 OOM
- [ ] 隐藏文件开关即时生效
- [ ] 排序四种方式 × 升降序，目录始终在前
- [ ] 过滤关键字与扩展名
- [ ] 书签添加/删除/跳转

### 3.1.1 列表缩略图

- [ ] 图片行首显示缩略图；解码完成前显示图片图标，换图时文件名不位移
- [ ] 视频行首显示代表帧（mp4/mkv/mov/webm）
- [ ] 坏图（扩展名对、内容是垃圾）：显示图标，且滚来滚去不会反复卡一下
- [ ] 透明 PNG：透明区域露出底色，不是黑块
- [ ] 4000x100 长截图：缩略图不是 3 像素高的黑线（采样率按宽高共同判断）
- [ ] 3000x4000 竖拍、1920x1080 横拍：等比裁切，不变形
- [ ] 60 张照片的目录快速滑动，`dumpsys gfxinfo` Janky frames 为 0
- [ ] 杀进程后重开同一目录：缩略图立即出现，`cache/thumbs` 里文件 mtime 未变（命中磁盘缓存）
- [ ] 同名覆盖一张图片（大小/时间变化）后刷新：缩略图更新为新图
- [ ] 压缩包内图片条目：仍是图标，不做解码
- [ ] 缩略图磁盘缓存超过 64 MB 后，最旧的文件被删到 48 MB

### 3.1.2 文件类型图标

- [ ] 17 类各放一个文件，图标互不相同、同屏风格一致（同一套纸形/折角/角标位置）
- [ ] 角标文字拼写正确（JPG/MP4/MP3/APK/ZIP/TXT/PDF/DOC/XLS/PPT/SRC/CFG/SH/DB/TTF/FILE）
- [ ] 无扩展名、`.gitignore`、乱扩展名：灰色问号图标，不猜
- [ ] 大小写：`A.PNG`、`APP.APK`、`Manual.PDF` 与全小写同图标
- [ ] `.js` 显示源码图标、`.json` 显示配置图标、`.sh` 显示脚本图标（顺序不能串）
- [ ] `x.tar.gz` 显示压缩包图标（只看最后一段）
- [ ] 深色 / 浅色主题：图标自带配色，不被主题色染成单色
- [ ] 透明背景：行背景色能透过来，图标周围没有白色/黑色方块底

### 3.2.1 多选与批量重命名

- [ ] 多选 N 项后长按**已选**条目：菜单标题为「已选 N 项」，所有操作作用于整批，选区不被打散
- [ ] 多选 N 项后长按**未选**条目：选区改成该条，菜单退回单条版本
- [ ] 多选菜单不含「打开方式…」「解压」；工具子菜单为「批量修改权限」「复制 N 个路径」
- [ ] 多选属性：名称/目录/大小合计/文件数/文件夹数，「更多」展开时间/权限/所有者
- [ ] 多选属性：权限不一致时显示「各不相同」；选目录时递归统计
- [ ] 批量重命名-序号：留空 → 原名+序号；`IMG_#`、`p##`、纯名称 三种写法
- [ ] 批量重命名-序号：>99 项时序号自然进位，补零位数不串
- [ ] 批量重命名-查找替换：只换主名不动扩展名；留空替换=删除；查找留空时全部「未改动」且「应用」不可点
- [ ] 批量重命名：预览拒绝空名、非法字符（`/`）、255 字节超长、批内重名、目录内已有同名
- [ ] 批量重命名：确认后实际文件名与预览一致，操作后选区清空、列表刷新
- [ ] 批量改权限：单条回填自身权限位，多条默认 644
- [ ] 工具子菜单在单条/多条下都能打开（`工具` → 二级页 → `返回` 回到网格）

### 3.2.2 权限面板

- [ ] 属性 → 修改权限：九个方格回填当前权限（`660` → 所有者读写、用户组读写、其它全空）
- [ ] 逐格切换，底部预览同步变化（`660` → 勾「其它-执行」变 `rw-rw---x（661）`）
- [ ] 特殊权限：勾「设置UID」显示 `rwSrw---x（4661）`；勾上执行位后变小写 `s`
- [ ] 粘滞位 + 其它执行 → `rwxrwxrwt（1777）`
- [ ] 多选 → 属性 → 修改权限：标题显示「已选 N 项」，确定后整批应用并提示「权限已更新」
- [ ] 右上角 `?` 打开「权限说明」，可滚动读完五节；关闭后权限面板仍在且勾选不丢
- [ ] `.sh` 点击面板：标题显示 `当前权限 rw-rw----（660）`，权限格子中 660 高亮且排在最前
- [ ] `/sdcard` 下 chmod 返回成功但权限不变（FUSE），不报错

## 5. 性能基线

| 指标 | 目标 |
| --- | --- |
| 冷启动到首屏 | < 1.5 s |
| 1000 项目录加载 | < 300 ms |
| 滚动帧率 | ≥ 55 fps |
| 照片目录滚动 | Janky frames = 0（60 项，`dumpsys gfxinfo`） |
| 缩略图缓存 | 内存 ≤ 32 MB；磁盘 ≤ 64 MB |
| 复制速度 | ≥ 30 MB/s（模拟器共享盘） |
| 内存峰值（浏览） | < 200 MB |
