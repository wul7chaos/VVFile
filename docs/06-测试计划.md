## 3. 功能清单

### 3.1 浏览

- [ ] 冷启动进入首页，双窗格均显示 `/sdcard`
- [ ] 左右窗格独立前进/后退/上级，历史不串
- [ ] 面包屑点击任意层级跳转正确
- [ ] 空目录、无权限目录、超长文件名、中文/emoji/空格文件名
- [ ] 5000+ 项目录滚动不卡顿、不 OOM
- [ ] 隐藏文件开关即时生效
- [ ] 排序四种方式 × 升降序，目录始终在前
- [ ] 过滤关键字与扩展名
- [ ] 书签添加/删除/跳转

### 3.2 文件操作

- [ ] 新建文件夹（含非法字符 `/ \ : * ? " < > |`）
- [ ] 新建空文件
- [ ] 重命名：同名、空名、跨扩展名、已存在
- [ ] 复制 1 个文件 / 100 个文件 / 1 GB 目录
- [ ] 跨窗格复制、跨分区复制
- [ ] 移动同分区（应为 rename，秒完成）
- [ ] 移动跨分区（复制+删除，失败时源保留）
- [ ] 复制冲突：覆盖 / 跳过 / 重命名 / 取消
- [ ] 删除单个、批量、非空目录、只读文件
- [ ] 取消复制后无 `.vvfile_tmp_*` 残留
- [ ] 压缩 zip（空目录/大文件/中文名）
- [ ] 解压 zip（含嵌套目录、恶意 `../` 路径应被拒绝）
- [ ] 分享单文件/多文件到其他应用
- [ ] 打开方式：文本、图片、视频、未知类型
- [ ] 属性显示大小/时间/权限正确

### 3.2.1 多选与批量重命名

- [ ] 多选 N 项后长按**已选**条目：菜单标题为「已选 N 项」，所有操作作用于整批，选区不被打散
- [ ] 多选 N 项后长按**未选**条目：选区改成该条，菜单退回单条版本
- [ ] 多选菜单不含「打开方式…」「解压」；工具子菜单为「批量修改权限」「复制 N 个路径」
- [ ] 多选属性：名称/目录/大小合计/文件数/文件夹数，「更多」展开时间/权限/所有者
- [ ] 多选属性：权限不一致时显示「各不相同」；选目录时递归统计
- [ ] 批量重命名-序号：留空 → 原名+序号；`IMG_#`、`p##`、纯名称 三种写法
- [ ] 批量重命名-序号：>99 项时序号自然进位，补零位数不串
- [ ] 批量重命名-查找替换：只换主名不动扩展名；留空替换=删除；查找留空时全部「未改动」且「应用」不可点
- [ ] 批量重命名：预览拒绝空名、非法字符（`/`）、255 字节超长、批内重名、目录内已有同名
- [ ] 批量重命名：确认后实际文件名与预览一致，操作后选区清空、列表刷新
- [ ] 批量改权限：单条回填自身权限位，多条默认 644
- [ ] 工具子菜单在单条/多条下都能打开（`工具` → 二级页 → `返回` 回到网格）

### 3.2.2 权限面板

- [ ] 属性 → 修改权限：九个方格回填当前权限（`660` → 所有者读写、用户组读写、其它全空）
- [ ] 逐格切换，底部预览同步变化（`660` → 勾「其它-执行」变 `rw-rw---x（661）`）
- [ ] 特殊权限：勾「设置UID」显示 `rwSrw---x（4661）`；勾上执行位后变小写 `s`
- [ ] 粘滞位 + 其它执行 → `rwxrwxrwt（1777）`
- [ ] 多选 → 属性 → 修改权限：标题显示「已选 N 项」，确定后整批应用并提示「权限已更新」
- [ ] 右上角 `?` 打开「权限说明」，可滚动读完五节；关闭后权限面板仍在且勾选不丢
- [ ] `.sh` 点击面板：标题显示 `当前权限 rw-rw----（660）`，权限格子中 660 高亮且排在最前
- [ ] `/sdcard` 下 chmod 返回成功但权限不变（FUSE），不报错



### 3.3 root 与系统分区

- [ ] 无 root 时访问 `/data` 提示明确，不崩溃
- [ ] 有 root 时浏览 `/data/data`、`/system`
- [ ] root 复制 `/system` 文件到 `/sdcard`（读）
- [ ] root 删除测试文件（写）
- [ ] 拒绝 su 授权后不再反复弹窗，设置页可重置
- [ ] 只读分区写入提示，不产生半成品

### 3.4 终端（真 PTY）

- [ ] `ls`、`pwd`、`cd /sdcard`、`echo` 正常
- [ ] `stty size` 与实际行列一致，横竖屏切换后跟随变化
- [ ] `tty` 输出 `/dev/pts/N`（确认跑在伪终端上）
- [ ] `echo $TERM` 为 `xterm-256color`
- [ ] 原生 `clear` 清屏；`Tab` 补全目录名
- [ ] `sleep 100` 后 `^C` 中断，退出码 130
- [ ] `top` / `vi` 全屏程序可进入，表头反显、`q` 退出
- [ ] root 会话 `id` 返回 uid=0，顶栏出现 `root` 徽标，`exit` 回普通会话且历史仍在
- [ ] `sudo <命令>` 以 root 执行且会话身份不变
- [ ] 单击唤出输入法、双指捏合改字号、长按进入选区并复制
- [ ] 长输出（10 万行）不卡死，回滚 5000 行
- [ ] `exit` 后会话状态正确，点 ↻ 可重开

### 3.5 编辑器

- [ ] 打开 UTF-8 / GBK / 带 BOM 文本
- [ ] 编辑后保存，内容与换行不变
- [ ] 未保存返回有确认

### 3.7 设置与主题

- [ ] 设置重启后保持

## 4. 健壮性 / 异常

- [ ] 操作中旋转屏幕不中断任务
- [ ] 操作中杀进程重启，无临时文件堆积
- [ ] 存储空间不足时复制失败并提示
- [ ] 拔掉/卸载 SD 卡（模拟器可跳过）
- [ ] 符号链接不递归死循环
- [ ] 文件名含 `'`、换行、控制字符时 shell 转义正确
