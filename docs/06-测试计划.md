# 测试计划

## 1. 测试分层

| 层级 | 范围 | 工具 | 频率 |
| --- | --- | --- | --- |
| 单元测试 | PathUtils、SortSpec、SizeFormatter、Zip Slip 防护、命令转义 | JUnit4 | 每次提交 |
| 集成/手工 | 文件操作、root、终端、编辑器 | MuMu 模拟器 | 每个里程碑 |
| 回归 | 下方清单全量 | 手工 + 截图 | 发布前 |

## 2. 环境矩阵

| 场景 | 配置 |
| --- | --- |
| A | MuMu Android 15，root 开启，已授予所有文件权限 |
| B | MuMu Android 15，root 关闭，仅普通权限 |
| C | 单窗格模式 + 浅色主题 |
| D | 深色 + 字体缩放 200% |

## 3. 功能清单

### 3.1 浏览

- [ ] 冷启动进入首页，双窗格均显示 `/sdcard`
- [ ] 左右窗格独立前进/后退/上级，历史不串
- [ ] 面包屑点击任意层级跳转正确
- [ ] 空目录、无权限目录、超长文件名、中文/emoji/空格文件名
- [ ] 5000+ 项目录滚动不卡顿、不 OOM
- [ ] 隐藏文件开关即时生效
- [ ] 排序四种方式 × 升降序，目录始终在前
- [ ] 过滤关键字与扩展名
- [ ] 书签添加/删除/跳转
- [ ] 搜索递归命中并能定位

### 3.2 文件操作

- [ ] 新建文件夹（含非法字符 `/ \ : * ? " < > |`）
- [ ] 新建空文件
- [ ] 重命名：同名、空名、跨扩展名、已存在
- [ ] 复制 1 个文件 / 100 个文件 / 1 GB 目录
- [ ] 跨窗格复制、跨分区复制
- [ ] 移动同分区（应为 rename，秒完成）
- [ ] 移动跨分区（复制+删除，失败时源保留）
- [ ] 复制冲突：覆盖 / 跳过 / 重命名 / 取消
- [ ] 删除单个、批量、非空目录、只读文件
- [ ] 取消复制后无 `.vvfile_tmp_*` 残留
- [ ] 压缩 zip（空目录/大文件/中文名）
- [ ] 解压 zip（含嵌套目录、恶意 `../` 路径应被拒绝）
- [ ] 分享单文件/多文件到其他应用
- [ ] 打开方式：文本、图片、视频、未知类型
- [ ] 属性显示大小/时间/权限正确

### 3.3 root 与系统分区

- [ ] 无 root 时访问 `/data` 提示明确，不崩溃
- [ ] 有 root 时浏览 `/data/data`、`/system`
- [ ] root 复制 `/system` 文件到 `/sdcard`（读）
- [ ] root 删除测试文件（写）
- [ ] 拒绝 su 授权后不再反复弹窗，设置页可重置
- [ ] 只读分区写入提示，不产生半成品

### 3.4 终端

- [ ] `ls`、`pwd`、`cd /sdcard`、`echo` 正常
- [ ] root 会话 `id` 返回 uid=0
- [ ] 长输出（10 万行）不卡死，环形缓冲生效
- [ ] 命令历史上下键
- [ ] 清屏、复制输出
- [ ] `exit` 后会话状态正确

### 3.5 编辑器

- [ ] 打开 UTF-8 / GBK / 带 BOM 文本
- [ ] 编辑后保存，内容与换行不变
- [ ] 未保存返回有确认
- [ ] 查找/替换
- [ ] 10 MB 文件走只读预览不卡死

### 3.6 应用管理

- [ ] 列表加载图标与大小
- [ ] 启动应用、打开应用详情
- [ ] 导出 APK 到当前目录，文件可安装
- [ ] 卸载普通应用；系统应用提示需要 root

### 3.7 设置与主题

- [ ] 四种主题切换即时生效
- [ ] 强调色 6 种切换
- [ ] 单/双窗格切换
- [ ] 启动路径恢复
- [ ] 设置重启后保持

## 4. 健壮性 / 异常

- [ ] 操作中旋转屏幕不中断任务
- [ ] 操作中杀进程重启，无临时文件堆积
- [ ] 存储空间不足时复制失败并提示
- [ ] 拔掉/卸载 SD 卡（模拟器可跳过）
- [ ] 符号链接不递归死循环
- [ ] 文件名含 `'`、换行、控制字符时 shell 转义正确

## 5. 性能基线

| 指标 | 目标 |
| --- | --- |
| 冷启动到首屏 | < 1.5 s |
| 1000 项目录加载 | < 300 ms |
| 滚动帧率 | ≥ 55 fps |
| 复制速度 | ≥ 30 MB/s（模拟器共享盘） |
| 内存峰值（浏览） | < 200 MB |
