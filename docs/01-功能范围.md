# 功能范围

按优先级划分。P0 = 首个可交付版本必须完成；P1 = 紧随其后；P2 = 可选增强。
**排除项**在最后单独列出，任何实现都不得引入。

## 1. P0 — 核心文件管理

### 1.1 浏览

- 双窗格文件列表，窗格独立导航与历史（前进/后退/上级）
- 活动窗格：在哪个窗格点击/滑动/拖拽，就把它设为活动窗格（不用先点顶部标签）
- 单窗格模式（设置切换）；底部「同步」把**未选中**窗格的路径改成和选中窗格一样
  （原来是「交换」，两边对调，实际用起来多是同一目录双窗对照，所以改成单向同步）
- 顶部「⋮」菜单：回到根目录（`/storage/emulated/0`）、显示/隐藏隐藏文件、同步窗格
- 路径栏只显示当前位置（根目录钉在最左，其余层级横向滚动跟随），**点一下打开跳转面板**；
  长按复制完整路径。不再支持「点某一段跳那一层」——深层路径下小字容易点错，
  要往上走用底部「上级」或返回键
- 跳转面板：预填当前路径，可直接编辑；输入时按「所在目录 + 名字前缀」实时给候选
  （目录候选带尾斜杠，点一下补全并继续列出它的内容）；`粘贴` 从剪贴板取值，
  `确定` 或键盘 Go 直接跳转
- 路径栏不再显示条目数量（「0 个文件夹 · 14 个文件」那一行仍然保留）
- 目录统计：当前目录文件夹数、文件数；容量卡片取当前卷的真实分区，命中 tmpfs/伪文件系统
  （`/storage`、`/proc` 等）时回退到 `/storage/emulated/0`，不会把 7.4 GB 的 tmpfs 当成内部存储
- 列表字段：图标、名称、大小、修改时间；详细模式显示权限/所有者
- 隐藏文件开关（`.` 开头）
- 排序：名称 / 大小 / 类型 / 修改时间，升序/降序，目录优先
- 过滤：按扩展名/关键字过滤当前列表
- 下拉刷新：每个窗格独立，在当前窗格任意位置（含空白处、空目录、错误态）下拉即刷新该窗格，
  拖动时显示「下拉刷新 / 释放刷新 / 刷新中…」提示
- 书签：按需求移除，不再实现
- 返回行为：返回键 / 全面屏侧滑 → 上一层目录；**已经在根目录 `/` 时什么都不做**，
  不再退出应用（手势导航下很容易一滑就退回桌面）
- 抽屉只从左上角菜单按钮打开，边缘侧滑不再触发抽屉，避免抢占系统返回手势
- 抽屉关闭：返回键、点侧栏右侧未覆盖区域（自绘遮罩，material3 默认遮罩在
  `gesturesEnabled = false` 时点了不关）
- 抽屉标题栏（VV logo / 名称 / 版本）即「关于」入口，点开显示版本与功能说明
- **「定位所在目录」**：在其他应用里对文件点「打开方式 → 定位所在目录」，跳进 VVFile 并把
  一个窗格定位到该文件所在目录、选中该文件（目录则直接进入）
  - 入口是独立的 `LocateActivity`，带 `android:label`，所以在系统选择器里显示的就是
    「定位所在目录」这四个字，而不是笼统的应用名
  - 支持 `ACTION_VIEW`（content/file）与 `ACTION_SEND`（`EXTRA_STREAM`）
  - Uri → 路径只解析不拷贝：externalstorage 文档（`primary:Download/a.zip`）、
    MediaStore 文档（`image:123`）、Downloads 文档，以及带 `_data` 列的提供者；
    解析不到就提示「无法定位该文件」

### 1.2 选择

- 点击进入目录/打开文件
- 长按进入多选，支持全选、反选；区间选择留待后续
- 选择集跨操作保留，切换目录清空（可配置）
- 底部工具条随选择态切换为操作条

### 1.2.1 长按操作菜单

- 长按任意条目（文件或目录）在**屏幕正中**弹出操作菜单。按下的条目若已在选区里，
  菜单作用于**整批已选条目**；否则把它设为唯一选中项（对齐 MT）
- 单条菜单项：复制 / 移动 / 删除 / 重命名 / 工具 / 压缩 / 属性 / 分享 / 打开方式…
- 多选菜单（≥2 项）：标题显示「已选 N 项」+ 名称预览，菜单项改为
  复制 / 移动 / 删除 / **批量重命名** / 工具 / 压缩 / 属性 / 分享
  - 多选时没有「打开方式…」（一次只能打开一个文件），也不显示「解压」
  - 工具子菜单在多选时变成「批量修改权限」「复制 N 个路径」
- 复制、移动的方向文案随窗格变化：左窗格条目显示「复制 ->」「移动 ->」，右窗格条目显示「<- 复制」「<- 移动」
- 压缩包（zip / apk）额外多出「解压」「解压到…」
- 工具子菜单：修改权限、复制路径
- 不做：签名、添加书签

### 1.2.2 打开方式

- 列出内置「编辑文本」（文本类型才有）、内置播放器/图片查看器（媒体类型才有）与系统中能处理该类型的应用，点击直接拉起
- 系统应用走 FileProvider content:// + `setPackage`；类型与包名一并显示
- **点 `.zip` 不再问「用什么打开」，直接进压缩包浏览**（见 1.2.6）
- 不做内置查看器：十六进制、xml、dex、arsc、apk、apks、查看字体、导入签名、插件信息、.9 编辑、jar、class、对比结果

### 1.2.6 压缩包浏览

点 zip 进入独立页面，像文件夹一样逐层看：

- 顶部：关闭/返回、文件名、包内当前位置（`/` 或 `/docs`）与条目总数
- 列表：目录在前，文件在后；文件显示大小和修改时间（压缩包内没有权限/所有者）
- 点目录进入下一层，返回键先退一层、到包根再关闭
- 点文件：解到应用缓存 `cache/archive/` 再交给统一的打开逻辑（文本进编辑器、图片/视频进内置播放器、
  其余交系统），不污染原目录
- 安全：解压只取包内路径的最后一段做文件名，`../` 之类无法穿越；目录条目不落地
- 不做：包内搜索、增删改、分卷、加密压缩包的密码输入（留待后续）

### 1.2.3 批量重命名

刻意比 MT 简单：MT 那套 `{P}{S}{T}{E}{N}{zN}` 模板 + 正则开关 + EXIF 时间，八行说明没人看。
这里只有两个模式 + 实时预览，每一条改动都能当场看到。

| 模式 | 输入 | 结果示例 |
| --- | --- | --- |
| 序号 | 新名称留空 | `a.mp3` → `a01.mp3`、`a02.mp3`…（原名 + 序号） |
| 序号 | `IMG_#` | `IMG_01.jpg`、`IMG_02.jpg`… |
| 序号 | `p##` | 强制补零到 2 位；`####` 就是 4 位 |
| 序号 | `旅行`（没有 `#`） | `旅行01`、`旅行02`…（自动补序号，避免整批同名） |
| 查找替换 | 查找 `IMG_` / 替换 `旅行` | 只换主名，扩展名不动；区分大小写，命中全部替换 |

- 序号位数：一段单个 `#` 按条目数自动定位数（≥2 位），写两个以上 `#` 就按写的位数补零
- 扩展名永远保持原样；文件夹整个名字当主名，不按 `.` 拆
- 预览：条目多时只显示前 3 条 + 最后 1 条（首行看格式、末行看位数够不够）
- 校验（命中即不能点「应用」）：名称为空、含非法字符、超过 255 字节、批内重名、目录里已有同名
- 批内互换（a→b、b→a）不会被判成冲突，执行时先挪到临时名再落到目标名
- 不做：正则、EXIF 时间、把修改时间/大小写进名字、跨目录移动式重命名

### 1.2.4 属性

- **入口**：长按 → 属性（多选时也走这里，面板换成聚合版）
- 单条：类型 / 路径 / 大小 / 修改时间 / 权限 / 所有者 / 可读可写
- 多选（对齐 MT）：名称（最多列 8 个，其余 `…`）/ 目录 / 大小（合计，`2.99M (3132722)`）/
  文件数 / 文件夹数；「更多」展开修改时间（取最新）、文件权限（一致才显示，否则「各不相同」）、
  所有者与用户组（同上）
- 文件夹递归统计；无权限的子目录跳过并在面板上标注「统计值可能偏小」；递归上限 20 万个节点
- 面板底部「修改权限」是改权限的**唯一入口**（单条、多条都一样）

### 1.2.5 权限面板

从「属性 → 修改权限」进入，对齐 MT 的细节面板，不再是「权限（如 755）」输入框：

- 读 / 写 / 执行 × 所有者 / 用户组 / 其它，九个方格；逐格切换
- 特殊权限三个方格：设置UID / 设置GID / 粘滞
- 底部实时预览 `rw-rw----（660）`；带特殊位时是四位八进制（`4755`、`1777`），
  设了特殊位但没勾执行时显示大写 `S`/`T`（与 chmod 语义一致）
- 打开时回填**当前**权限位（从属性的符号串解析），多选时回填一致的那份，不一致按 644
- 右上角 `?` 打开「权限说明」：读/写/执行、所有者/用户组/其它、特殊权限、常用配置
  （644/755/600/660/777）、以及「/sdcard 是 FUSE，chmod 会被忽略」的提示
- 不做：符号模式输入（`u+x`）、递归改子项权限（P2）


### 1.3 文件操作

| 操作 | 说明 |
| --- | --- |
| 新建文件夹 | 支持批量命名、非法字符校验 |
| 新建文件 | 空文件，可选常用扩展名 |
| 重命名 | 单个直接改名；多个走批量重命名（序号模板 / 查找替换，见 1.2.3） |
| 复制 | 同窗格/跨窗格，冲突时覆盖/跳过/重命名/取消 |
| 移动 | 同上；跨分区自动退化为复制+删除 |
| 删除 | 二次确认，永久删除，无回收站 |
| 分享 | `ACTION_SEND` 多文件（FileProvider） |
| 打开方式 | 按 MIME 查询，支持指定应用 |
| 属性 | 单条详情（路径/大小/时间/权限/所有者），多选聚合（见 1.2.4） |
| 压缩 | 生成 ZIP（存储/Deflate），可选择压缩级别 |
| 解压 | ZIP 解压到当前目录/指定目录，防 Zip Slip |
| 权限修改 | chmod 单条或整批（root 或应用可写时） |

### 1.4 存储与权限

- Android 11+ 引导授予"所有文件访问权限"（MANAGE_EXTERNAL_STORAGE）
- 无权限时只展示应用私有目录并给出引导
- root 检测：`su -c id -u` == 0；root 状态展示在抽屉
- **不做任何非 root 提权**：不接入 Shizuku、ADB shell、无障碍/设备管理等特殊权限通道，
  特权操作有且仅有 root
- root 分区浏览：`/data`、`/system`、`/vendor` 等
- 只读分区写操作前提示，可尝试 `mount -o rw,remount`（P1）

### 1.5 终端

- 仿 MT 的命令行窗口：顶部「终端」+ 更多 + 关闭，中部终端区，底部两排功能键
- **真 PTY**：进程通过 `/dev/ptmx` 起在伪终端上（`jni/termux.c`），输出由 VT 仿真器解析，
  所以 `clear`、`vi`、`top`、`Tab` 补全、`Ctrl+C`、`SIGWINCH` 全部是真行为，App 侧不做任何模拟
- 提示符 `:/目录 $`（root 会话是 `#`）由 shell 的 `PS1` 直接绘制：
  `PS1=':${PWD} \$ '`，`cd` 之后下一条提示符自然更新，不再靠哨兵回传
- root 用命令切换，不用开关：`su` 就是往 PTY 里写 `su`，由系统 su 完成提权；
  顶栏 `root` 徽标读的是光标行上纯提示符的 `#`/`$`，不靠猜
- 两排功能键：Esc / Tab / PgUp / Home / ↑ / End / ^C / ⋮ 与 Ctrl / Alt / ^← / PgDn / ← / ↓ / → / ↻
  - PgUp/PgDn/Home/End 交给 shell（在 `top`/`vi` 里就是翻页），↑/↓ 是 shell 的行内历史
  - Ctrl / Alt 是粘滞键（按一次生效，随后的一个字符发完即释放）；`^C` 直接发 0x03 中断前台命令
  - `^←` 发 Ctrl+Left（按词跳），↻ 重开一个 PTY
- 手势：单指点击唤出/收起输入法，双指捏合改字号，长按进入选区（拖动两端手柄 + 复制/粘贴菜单）
- 更多菜单：清空 / 发送 Ctrl+C / 唤醒锁 / 结束 / 重置 / 设置 / 粘贴
  - **清空**：让 shell 自己执行 `clear`（先发 `^U` 丢掉正在输入的那半行，避免拼成一条
    怪命令），因此屏幕清空后提示符仍在、行编辑状态不错位，回滚区一并清掉；
    直接改 VT 缓冲会让 mksh 记住的光标列失真，不可取
  - `clear` / `cls` 由 `$ENV` 启动脚本里的函数提供，不依赖机型是否带 `clear` 二进制
- 回滚历史 5000 行，屏幕内容可整屏选中；窗口尺寸变化（横竖屏、输入法、改字号）会通过
  `TIOCSWINSZ` 通知 shell，`stty size` 与实际行列一致
- 配色跟随主题（深色黑底、浅色白底），前景/背景/光标三色可随主题切换
- exec 的是系统分区的 `/system/bin/sh`，**不需要降 targetSdk**（不受 Android 10+ W^X 限制）
- 允许直接执行 `sh` 脚本（用户显式输入）

### 1.5.1 shell 脚本（.sh / .bash）

- 点击脚本不直接进编辑器，先弹「执行 / 编辑 / 设置」菜单（对齐 MT 的做法）
- 设置里可选执行环境：系统环境（sh）/ ROOT 权限（su）；**不做扩展包环境**
- 执行权限默认显示**文件当前的真实权限**（标题行给出 `当前权限 rw-rw----（660）`），
  常用预设为 777 / 755 / 555 / 644 / 444；当前值不在预设里时把它补成一个格子放在最前面，
  命令为 `cd <目录> && chmod <权限> <文件> && sh <文件>`
- 选中 ROOT 时显示红字风险提示，root 不可用则只提示不执行
- 执行结果显示命令、退出码与输出，可滚动查看

### 1.6 文本编辑器

- 侧栏「文本编辑器」：新建临时 txt 并直接进入编辑，落在专属目录
  `/storage/emulated/0/VVFile/temp/新建文本-时间戳.txt`
- 打开文本文件，UTF-8 自动识别，GBK 兜底；可手动指定编码重新加载 / 保存
- 行号、等宽字体；关闭「自动换行」后长行横向滚动
- 纵向滚动条：可拖动滑块、可点轨道快速跳转，内容不足一屏自动隐藏
- 横向滚动条：关闭「自动换行」且内容超宽时出现在底部，同样支持拖动与点轨道
- 撤销 / 重做（上限 100 步）
- 「编辑」菜单（按行处理）：复制行、剪切行、删除行、清空行、替换行、重复行、
  转为大写、转为小写、增加缩进、减小缩进
- 「更多 → 文件」：另存为、重新加载文件、按 UTF-8/GBK 重新加载、
  保存为 UTF-8/GBK、换行符 LF/CRLF、统计
- 「更多」：文件、搜索、转到指定行、自动换行、只读模式、关闭文件
- 搜索面板：查找、上一个/下一个、替换、全部替换、Cc（区分大小写）、W（整词）、命中计数
- 保存、另存为、修改未保存提示；只读模式禁止编辑与保存
- 语法高亮：Kotlin/Java/JS/TS/C/C++/C#/Python/Ruby/Perl/PHP/Go/Rust/Swift/Dart/Shell、HTML/XML/SVG（标签/属性/值）
  等常见代码文件，可「更多 → 语法高亮」开关；超 60 K 字符自动关闭避免卡顿
- Markdown / HTML 预览：默认**左编辑右渲染**分栏，顶栏按钮可切换 分栏 → 仅编辑 → 仅预览
- Markdown 用 commonmark 转 HTML 后由 WebView 渲染；HTML 直接渲染，样式跟随主题深浅
- 大文件分两档处理：
  - **> 5 MB**：只读打开（禁止保存），正文改用「按行虚拟化的只读查看器」，
    一行一个 `LazyColumn` item，任意大小都是秒开；带行号、可拖动进度条、可跳行、可长按选中复制
  - **> 16 MB**：只载入前 16 MB，顶部提示「只载入了前 16 MB」
  - 阈值 200 K 字符（约 400 KB 中文）以上一律走查看器：单个 `BasicTextField`
    渲染几十万字符会让主线程卡十几秒并可能 OOM
- 查看器模式下「搜索」「转到指定行」「HTML/Markdown 预览」自动隐藏/禁用，
  因为它们是按整段文本做高亮的，在虚拟化列表上没有意义；跳行改用查看器顶部的「跳转行」

### 1.7 已安装应用

- 应用列表（名称、包名、版本、图标、大小）
- 列表来源：有 root 走 `su -c pm list packages -f -U`（可覆盖 PackageManager 可见性受限的包），
  无 root 走 PackageManager（依赖 `QUERY_ALL_PACKAGES`）
- 点击列表项展开功能面板：启动、应用信息、导出 APK、卸载（系统应用置灰）
- 「应用信息」为自带弹窗（不做签名状态、加固状态、UID，也不做目标/最低系统）：
  包名、版本号、安装包大小、目标架构（APK 内 `lib/<abi>/` 实测）、
  数据目录、数据目录 2、APK 路径、首次安装、最后更新；长路径单行横向滚动
- 弹窗交互：点任意一行复制该行内容；数据目录类行点击直接跳到该目录，长按复制
- 弹窗底部：更多（跳系统「应用信息」）/ 提取安装包（导出到 `VVFile/apk`）
- 导出 APK 到专属目录 `/storage/emulated/0/VVFile/apk`（纯文件复制，不做反编译）
- 搜索与「系统应用」过滤
- 列表布局对齐 MT：顶部返回 / 标题 / 搜索 / 更多（排序方式、全选，按需求不做「设置」），
  下面「用户应用 / 系统应用」两个页签，每项三行：名称；版本 + 安装包大小（23.14M 这种紧凑写法）；包名
- 排序：应用名称 / 应用包名 / 安装包大小 / 首次安装时间 / 最后更新时间，可勾选逆向排序
- 多选：长按或菜单「全选」进入选择态，底部可批量导出 APK（逐个导出，进度显示第 i/N 个）
- 列表缓存：进程内缓存应用列表（含图标），再次打开直接命中缓存，不再每次重扫
  - 缓存校验走 `PackageManager.getChangedPackages(sequence)`（API 26+）：只返回上次扫描之后变化的包，
    没有变化直接用缓存；序列太旧返回 null 时回退全量扫描
  - 监听 `PACKAGE_ADDED / REMOVED / REPLACED / CHANGED` 广播，安装、卸载、更新后自动失效缓存并立刻重扫
  - 支持下拉刷新强制全量重扫；页面重新可见时做一次轻量校验

### 1.7.1 专属目录

参考 MT 管理器「文件都在 `/storage/emulated/0/MT2/` 子目录」的习惯，VVFile 生成的文件统一放在
`/storage/emulated/0/VVFile/`：

```
VVFile/
├── apk/    已安装应用导出的 APK
└── temp/   编辑器新建的临时 txt
```

目录按需创建；共享存储不可用时回退到应用私有目录（`Android/data/.../files/apk`、`cache/editor`）。

### 1.9 媒体播放

点击音频 / 视频 / 图片类文件直接进内置播放器（不再弹系统选择器），同目录同类型文件自动排成播放列表。
类型识别见 `MediaFormats`：音频 20 种、视频 18 种、图片 10 种扩展名。

#### 1.9.1 音频

- 面板结构（对齐 MT）：右上角标题、专辑圆盘、名称与所在目录、进度条与双时间、播放模式 / 上一首 / 播放暂停 / 下一首 / 播放列表、底部倍速 0.5x–2.0x
- 右上角两个按钮：**最小化**、**关闭**（按需求新增）
- 播放模式按钮依次切换：列表循环 → 单曲循环 → 随机 → 不循环；**随机只打乱当前队列**，队列就是目标文件所在目录下的同类型文件，不跨目录
- 最小化后收成浏览器底部的迷你条（名称、播放/暂停、展开、关闭），播放继续
- 后台播放：`AudioPlaybackService`（media3 `MediaSessionService`）在前台服务里持有播放器，
  通知栏显示标题 / 目录 / 进度与上一首、播放暂停、下一首；锁屏与耳机键同样可用
- 关闭按钮会停播并清空队列，通知随之消失
- 不做「定时关闭」（按需求移除）
- 解码失败时在名称下方红字给出原因（文件不存在 / 无权限 / 格式不支持）

#### 1.9.2 视频

- 整页沉浸播放（隐藏系统栏、保持常亮），单击切换控件的显隐，控件 4 秒自动隐藏
- 控件：返回、标题、进度、时间、上一集 / 播放暂停 / 下一集、倍速、设置
- 设置面板分四组（对齐 MT，去掉「定时关闭」）：
  - 显示：强制铺满全屏、拉伸以铺满全屏、自适应横竖屏
  - 播放：开启循环播放、开启随机播放、自动播放下一集
  - 轨道：音轨、字幕（内嵌轨道，可切换或关闭字幕）
  - 播放速度：0.5 / 1.0 / 1.25 / 1.5 / 2.0 / 3.0
- 按需求**不**在通知栏驻留；打开视频时自动暂停后台音频
- 循环 / 随机 / 自动下一集都作用在同一个队列（目标文件所在目录的同类型文件），随机不会跨目录

#### 1.9.3 图片

- 同目录**左右滑动 / 上下滑动**都按顺序切上一张、下一张（上滑看下一张，下滑回上一张）
- 双指缩放（1x–8x）、双击放大/还原、放大后单指拖动平移；未放大时横向滑动交给翻页
- 单击隐藏/显示顶栏
- Android 9+ 用系统 `ImageDecoder` 解码，GIF 直接播放动画；超大图按 2 的幂降采样（上限 2048px）防 OOM

## 5. 验收口径

- 所有 P0 操作在 MuMu（Android 15）上手工走通，无崩溃
- 普通目录与 root 目录各跑一遍复制/移动/删除/重命名
- 1 GB 以上目录复制可取消、进度不倒退、取消后无残留临时文件
- 冷启动到可浏览 < 1.5 s（模拟器基线）
- 无网络权限；卸载后无残留（除用户主动导出文件）
