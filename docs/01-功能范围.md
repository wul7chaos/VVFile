# 功能范围

按优先级划分。P0 = 首个可交付版本必须完成；P1 = 紧随其后；P2 = 可选增强。
**排除项**在最后单独列出，任何实现都不得引入。

## 1. P0 — 核心文件管理

### 1.1 浏览

- 双窗格文件列表，窗格独立导航与历史（前进/后退/上级）
- 单窗格模式（设置切换），窗格间一键交换路径
- 路径面包屑，可点击任意层级；长按可复制路径
- 目录统计：当前目录文件夹数、文件数、分区已用/总量
- 列表字段：图标、名称、大小、修改时间；详细模式显示权限/所有者
- 隐藏文件开关（`.` 开头）
- 排序：名称 / 大小 / 类型 / 修改时间，升序/降序，目录优先
- 过滤：按扩展名/关键字过滤当前列表
- 书签：按需求移除，不再实现

### 1.2 选择

- 点击进入目录/打开文件
- 长按进入多选，支持全选、反选；区间选择留待后续
- 选择集跨操作保留，切换目录清空（可配置）
- 底部工具条随选择态切换为操作条

### 1.3 文件操作

| 操作 | 说明 |
| --- | --- |
| 新建文件夹 | 支持批量命名、非法字符校验 |
| 新建文件 | 空文件，可选常用扩展名 |
| 重命名 | 单个/批量（P1），保留扩展名选项 |
| 复制 | 同窗格/跨窗格，冲突时覆盖/跳过/重命名/取消 |
| 移动 | 同上；跨分区自动退化为复制+删除 |
| 删除 | 二次确认，永久删除，无回收站 |
| 分享 | `ACTION_SEND` 多文件（FileProvider） |
| 打开方式 | 按 MIME 查询，支持指定应用 |
| 属性 | 名称、路径、大小、时间、权限、所有者、MD5/SHA-1（P1） |
| 压缩 | 生成 ZIP（存储/Deflate），可选择压缩级别 |
| 解压 | ZIP 解压到当前目录/指定目录，防 Zip Slip |
| 权限修改 | chmod（root 或应用可写时） |

### 1.4 存储与权限

- Android 11+ 引导授予"所有文件访问权限"（MANAGE_EXTERNAL_STORAGE）
- 无权限时只展示应用私有目录并给出引导
- root 检测：`su -c id -u` == 0；root 状态展示在抽屉
- **不做任何非 root 提权**：不接入 Shizuku、ADB shell、无障碍/设备管理等特殊权限通道，
  特权操作有且仅有 root
- root 分区浏览：`/data`、`/system`、`/vendor` 等
- 只读分区写操作前提示，可尝试 `mount -o rw,remount`（P1）

### 1.5 终端

- 内置终端页，默认 `sh`，可切换 root shell
- 命令输入、输出滚动、清屏、复制输出
- 命令历史（上下键）、常用命令快捷条
- 允许直接执行 `sh` 脚本（用户显式输入）

### 1.6 文本编辑器

- 打开文本文件，UTF-8 自动识别，GBK 兜底
- 行号、等宽字体、横竖滚动
- 查找/替换、跳转行
- 保存、另存为、修改未保存提示
- 大文件保护：> 5 MB 提示只读预览

### 1.7 已安装应用

- 应用列表（名称、包名、版本、图标、大小）
- 启动、应用详情、卸载（系统应用需 root）
- 导出 APK 到当前目录（纯文件复制，不做反编译）
- 搜索与排序

### 1.8 设置

- 主题：深色 / 浅色 / 纯黑 / 跟随系统
- 强调色选择（预设 6 色）
- 单/双窗格、启动路径、启动时恢复上次路径
- 默认排序、隐藏文件、目录优先
- root 请求策略：自动 / 每次询问 / 禁用
- 终端字体大小、编辑器字体大小

## 2. P1 — 增强

- 批量重命名（序号、替换、正则预览）
- 文件校验（MD5 / SHA-1 / SHA-256）
- 存储分析：目录大小排行、大文件 Top N
- 归档格式扩展：tar / tar.gz / 7z 只读浏览
- 图片/文本快速预览（不进入编辑器）
- 多标签页（每个窗格多 Tab）
- 书签拖拽排序、导入导出
- 分区挂载读写（remount）
- 根目录文件搜索（`find`），支持按大小/时间过滤

## 3. P2 — 可选

- SMB / WebDAV 网络位置
- 自定义主题（导入配色）
- 归档创建格式扩展
- 平板/横屏专用布局（三栏）

## 4. 明确排除

| 功能 | 原因 |
| --- | --- |
| APK 修改、DEX 编辑、签名、汉化 | 产品边界，专注文件管理 |
| 会员、登录、支付 | 产品边界 |
| Activity 记录、调试注入 | 产品边界 |
| 插件系统、脚本市场 | 产品边界 |
| Shizuku / ADB shell / 无障碍提权 | 特殊权限只保留 root |
| 回收站 | 产品边界 |
| MCP 服务 | 产品边界 |
| 广告、统计、账号云同步 | 隐私与轻量目标 |
| 应用克隆/破解相关能力 | 合规风险 |

## 5. 验收口径

- 所有 P0 操作在 MuMu（Android 15）上手工走通，无崩溃
- 普通目录与 root 目录各跑一遍复制/移动/删除/重命名
- 1 GB 以上目录复制可取消、进度不倒退、取消后无残留临时文件
- 冷启动到可浏览 < 1.5 s（模拟器基线）
- 无网络权限；卸载后无残留（除用户主动导出文件）
