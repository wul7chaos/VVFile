## 4. 已知限制

1. MuMu 镜像无 `su`：root 读写、root 终端、系统分区 chmod 只能依赖单测与后续真机复测。
2. `/sdcard` FUSE 不生效 `chmod`，权限修改需在 ext4/root 分区验证。
3. Release 使用 debug 签名，仅用于本地验收；正式分发需替换为独立 keystore。
4. 空目录压缩提示「没有可压缩的内容」，不会生成仅含目录条目的 ZIP（符合当前设计）。

P0 范围内的浏览、选择、文件操作、压缩/解压、编辑器、终端、应用管理、设置、root 通道均已落地；可安装的 1.0.0 Release 构建通过并完成冒烟。剩余工作为有 root 真机的复测与正式签名分发。
