# VVFile 项目概述

> 一个面向 Android 的本地文件管理器，交互框架参考 MT 管理器的双窗口工作流，
> 但视觉语言、信息架构、命名与实现全部自研。**不包含** APK 修改/签名、会员、
> Activity 记录、插件、回收站、MCP 等模块。

## 1. 项目定位

| 项 | 内容 |
| --- | --- |
| 名称 | VVFile |
| 包名 | `com.vvfile.app` |
| 平台 | Android 8.0+（minSdk 26），targetSdk 36 |
| 语言 | Kotlin |
| UI | Jetpack Compose + Material 3 |
| 核心场景 | 双窗口文件浏览、批量文件操作、root 分区访问、内置终端、文本编辑 |
| 参考对象 | MT 管理器（仅参考功能与交互习惯，不复制资源、文案、代码） |
| 测试设备 | MuMu 模拟器 Android 15（adb `127.0.0.1:16384`） |

## 2. 设计目标

1. **双窗口即工作台**：左右两个独立目录窗格，复制/移动天然跨窗口，减少来回跳转。
2. **本地优先、root 增强**：普通目录走 `java.nio`，系统分区改走 `su` 执行，
   无 root 时明确提示而不是静默失败。
3. **操作可预期**：所有批量操作有进度、可取消、失败项汇总，不做"假成功"。
4. **轻量无广告**：无账号、无会员、无统计 SDK、无网络权限（首版）。
5. **与 MT 有明确区隔**：不使用 MT 的蓝色/金色主色、不使用相同的图标与文案，
   布局上采用"分段窗格切换 + 底部工具条 + 抽屉式工具页"，而非 MT 的标题栏样式。

## 3. 非目标（明确不做）

- APK/DEX 反编译、修改、签名、汉化
- 会员/登录/支付/激活
- Activity 记录、调试注入、MCP 服务
- 插件体系、脚本市场
- 回收站（删除即删除，二次确认）
- 云盘、广告、埋点
- **Shizuku / ADB shell / 无障碍等一切非 root 提权通道**：特殊权限只走 root

## 4. 术语

| 术语 | 含义 |
| --- | --- |
| 窗格 Pane | 左右各一个文件列表，拥有独立的路径、历史栈、选择集 |
| 活动窗格 | 接收点击/长按/新建等操作的窗格，标题栏有强调色标记 |
| 根路径 | 需要 root 才能读写的路径，如 `/data`、`/system` |
| 降级执行 | 直接 IO 失败后改用 root shell（`su -c`）执行同一语义；无 root 则报错，不做其它提权 |
| 书签 | 用户收藏的目录，显示在抽屉与路径快捷区 |
