## 并行执行方式

里程碑内部按“契约先行 → 三路并行 → 合并窗口”推进，规则见
[`08-子代理并行开发规范.md`](08-子代理并行开发规范.md)。

| 波次 | 并行写者 | 内容 |
| --- | --- | --- |
| W0 | Lead | 契约、骨架、构建绿灯 |
| W1 | fs-core / ui-shell / root-shell | 只读内核 / 双窗格 UI / Shell 底座 |
| W2 | fs-core / ui-shell / tools | 复制引擎 / 选择与操作 UI / 编辑器 |
| W3 | root-shell / tools / qa | 系统分区与终端 / 应用·搜索·设置 / 回归 |
| W4 | Lead + qa | 性能、无障碍、发布 |

硬约束：每个文件同一时间只有一个写者；子代理使用独立 worktree 与分支；
只有 Lead 合并、改共享文件、跑集成构建与安装。

## 风险

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| Android 15 分区存储限制 | 普通目录读写受限 | MANAGE_EXTERNAL_STORAGE + SAF 兜底 |
| 模拟器共享盘性能差 | 大文件复制慢 | 进度显示 + 可取消，不阻塞 UI |
| root 实现差异（MuMu/KernelSU） | su 命令行为不同 | 可配置 su 命令，失败回退 |
| Compose 大列表性能 | 5000 项卡顿 | 稳定 key + 分页 emit + 固定行高 |
| 归档格式需求膨胀 | 工期 | 首版仅 ZIP，其他放 P1 |
